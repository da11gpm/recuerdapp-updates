# APK públicos de RecuerdApp

Este repositorio aloja las publicaciones de APK de RecuerdApp. La aplicación consulta la última publicación estable desde **Ajustes → Actualizar app** y descarga su APK sin pedir una cuenta de GitHub.

La primera publicación estará disponible en [Releases](https://github.com/da11gpm/recuerdapp-updates/releases) cuando se adjunte un APK de distribución firmado. Cada publicación debe incluir un único APK universal, con un `versionCode` mayor que el anterior y la misma clave de firma que las instalaciones existentes.

No publiques aquí claves de firma, claves API ni datos de usuarios.
